DriveDocs AI answers questions over manuals and diagrams. A LangChain agent searches passages (MiniLM + FAISS) and diagrams (CLIP + FAISS) as tools, answers only from what it retrieved, and every [Source, Page] citation is verified. Personal data is masked and injected instructions in documents are ignored. The demo uses a synthetic owner's manual for the fictional Northwind Aurora EV.

    How it works

    1. Ingest: validate, extract text per page and embedded images.
    2. Index: MiniLM (384-d) for text, CLIP (512-d) for images: separate FAISS indexes.
    3. Retrieve: an agent calls text and diagram search tools; per-modality relevance rules and caption-aware image ranking.
    4. Answer: Gemini writes from the evidence (or quotes it without an LLM); every citation is verified and PII is masked.
